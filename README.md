🎓 Smart Student Productivity Dashboard

A responsive, all-in-one student productivity dashboard designed to help students organize their academic activities, manage assignments, track study progress, and stay focused.

✨ Features

- 📊 Dashboard Overview – View tasks, assignments, total study time, and average grades in one place.
- 📚 Assignment Tracker – Add and manage assignments with subjects, deadlines, and priority levels.
- ⏱️ Pomodoro Timer – Improve focus with dedicated focus sessions, short breaks, and long breaks.
- ✅ To-Do List – Create, complete, and delete daily tasks.
- 📅 Weekly Timetable – Organize classes and activities by day and time.
- 💯 Grade Calculator – Calculate percentages, save marks, and track average grades.
- 📈 Study Statistics – Monitor task completion, study time, grades, and assignment progress.
- 📝 Notes Manager – Create, save, and manage personal study notes.
- 🎯 Study Goals – Set study goals and keep track of your study plan.
- 🌙 Dark Mode – Switch between light and dark themes.
- 🔎 Search – Find dashboard information quickly.
- 📱 Responsive Design – Use the dashboard on desktop, tablet, and mobile devices.
- 💾 Local Data Storage – Save tasks, assignments, grades, notes, and preferences in your browser using Local Storage.

🛠️ Technologies Used

- HTML5 – Application structure
- CSS3 – Styling, responsive layouts, and themes
- JavaScript – Interactive features and data management
- Browser Local Storage – Persistent storage of user data

🚀 Getting Started

Prerequisites

You only need a modern web browser. No additional software or dependencies are required to run the project locally.

💡 How to Use

1. Open the dashboard in your browser.
2. Add assignments with their subjects, due dates, and priorities.
3. Create daily tasks and mark them as completed.
4. Use the Pomodoro timer to manage focused study sessions.
5. Add classes to your weekly timetable.
6. Calculate and save your grades.
7. Track your academic progress through the statistics section.
8. Save study notes and set personal study goals.
9. Switch themes to choose your preferred appearance.

💾 Data Storage

The application uses browser Local Storage to save supported data between visits.

Note: Your data is stored locally in the browser rather than in a cloud database. It is not automatically synchronized across different devices or browsers. Clearing browser data may remove your saved information.

🎯 Project Objective

The goal of this project is to provide students with a simple, user-friendly platform for managing academic tasks, organizing schedules, tracking grades, and improving study habits in one place.
